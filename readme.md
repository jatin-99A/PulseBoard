# 📊 Live Polls Platform

A modern real-time polling platform that enables users to create, manage, and participate in live polls while tracking responses through an interactive analytics dashboard.

## 🚀 Features

- 🎯 Create and manage live polls
- ⚡ Real-time voting with instant updates
- 📊 Live analytics and insights
- 👥 Multi-user participation
- 🔗 Share polls using unique links or codes
- 🔐 Secure authentication and authorization
- 📱 Fully responsive UI
- 📈 Interactive charts and statistics
- 📜 Poll history and results

---

## 🛠️ Tech Stack

### Frontend
- Next.js (TypeScript)
- React
- Tailwind CSS
- Socket.IO Client
- Axios

### Backend
- Node.js
- Express.js (TypeScript)
- Socket.IO
- PostgreSQL
- Drizzle

### Authentication
- JWT (JSON Web Tokens)
- bcrypt
